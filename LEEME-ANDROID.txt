PIRARED ANDROID — PROYECTO PARA COMPILAR APK

Este ZIP es el código fuente de una app Android que abre el prototipo local de PiraRed en un WebView. Incluye las imágenes locales que estaban en el proyecto.

IMPORTANTE:
- Este archivo NO es todavía una APK instalable.
- La app es visual/de demostración. Registro, publicaciones y mensajes reales no están conectados a un servidor.
- Para obtener el APK gratis desde el celular, el proyecto incluye un flujo GitHub Actions:
  1. Crear/iniciar sesión en GitHub y crear un repositorio nuevo.
  2. Subir todos los archivos de esta carpeta al repositorio (incluido .github/workflows/build-apk.yml).
  3. Abrir la pestaña Actions y elegir “Build PiraRed APK”, luego “Run workflow”.
  4. Cuando termine correctamente, abrir la ejecución y descargar el artefacto “PiraRed-APK”.
  5. Extraer el artefacto ZIP; dentro estará app-debug.apk. Android puede pedir permiso para instalar desde esa fuente.

No publiques contraseñas ni claves privadas en el repositorio. El proyecto no requiere claves.
